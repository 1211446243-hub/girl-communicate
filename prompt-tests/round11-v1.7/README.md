# v1.7 测试材料说明

这些对话由仓库测试脚本构造并通过模型生成，仅用于功能验证，不是用户的真实聊天导出。包括危机、低落等场景也均为测试输入，不代表任何人的健康状况。

- `run-round11.js`：话题追发、主动聊天、危机关怀及回来后不埋怨的合成对话实测。
- `e2e-v17.js`：Electron 冒烟，使用独立临时 userData。`e2e-chat.png` 中是该脚本的合成场景，不含 Key 或真实个人资料。
- `00-汇总.md`、01～09 及 `results.json`：既有实测结果。自动判定通过不保证模型每次输出一致。
- 本次公开同步包排除了 `*.log`、旧截图/演示视频及所有二进制安装包；不包含运行期用户数据、设置或凭据。
- 单元测试里的凭据样式、号码样式等是用于敏感信息过滤的固定测试字符串，并非真实凭据或联系方式。
