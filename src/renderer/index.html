之间 · 作者 刘博宇SolarSystem

欢迎来到之间

她们用你自己的 DeepSeek API Key 聊天，费用直接从你的 DeepSeek 账户扣，软件里没有任何内置 Key。三步就能开始：

  1. 打开 ，注册并登录。
  2. 在「充值」里充一点余额，几块钱就能聊很久。
  3. 进入「API keys」，点「创建 API key」，复制那串 sk- 开头的字符。

把 Key 粘贴到这里

只保存在这台电脑上，用 Windows 系统加密存储。保存后会自动测一次连接。

连接成功

可以开始了。去选一个今晚想说话的人吧。把鼠标放在人设卡片上，能先看几句她平时怎么说话。

她记得的事

从你们的聊天里提炼出来、只保存在本机的几条小事，每次聊天都会悄悄带给她。可以改、删，也可以自己加。

    清空聊天记录

    清空前会自动备份，之后可以撤销或从备份恢复；勾选时她记得的事也一起备份、撤销时一起恢复。
