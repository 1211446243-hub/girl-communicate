# 之间

> 在你和她之间，留一盏夜灯。

「之间」是一个 Windows 桌面 AI 陪伴聊天软件：夜间柔光风的界面，七种性格的恋人角色，接入你自己的 DeepSeek API Key 就能聊。

## 更新说明（v1.7.0）

**回复更像真人**
- 她的回复不再一个字一个字往外蹦：顶部显示「正在输入…」，气泡里是三个跳动的点，整条打完才一起出现。从你发出消息算起，至少随机等 1～2 秒。

**她会顺着你的话再补一句**（设置 →「她主动找你」，默认「偶尔」）
- 她回完之后，如果你一两分钟（随机 40 秒～3 分钟）没说话，有时会顺着你刚聊到的某个东西再发一条。比如你说吃了火锅，过一会儿她可能来一句「毛肚是不是脆脆那种呀」。
- 「偶尔」大约三分之一的时候会补，延迟 40 秒～3 分钟；「正常」大约一半，延迟 40 秒～2.5 分钟。每轮最多补一次，不会连着追。
- 你一开始打字或者发消息，待发的那条就取消。你最后说「晚安」「先去忙了」，或最近没有可延伸的实质内容（只有「嗯」「好的」等），她就不补。若更早的消息还有话题，单独一句「嗯」并不保证取消追发。

**她会隔一阵主动找你**（同一处设置，默认「偶尔」）
- 软件开着时（包括缩在托盘里），如果你很久没聊，最近聊过的那一位会主动找你。她可能道早安、饭点问一句、分享自己的小事，也可能问问她记得的事，比如约好的事、最近的考试或面试。
- 长时间空闲的主动聊天（含温和关心）只在电脑本地时间 8:30（含）～23:30（不含）之间发；短时间的话题追发不受这个时段限制。
  - 「偶尔」：空闲 4～8 小时之后才发，每人每天最多 2 条，只找最近 7 天内聊过的 1 位。
  - 「正常」：空闲 2.5～5 小时之后才发，每人每天最多 3 条，最近 14 天内聊过的 2 位都可能找你。
  - 不同的人之间至少隔 90 分钟，不会 7 个人一起刷屏。
- 同一人设发了主动消息（包括话题追发）后，你没回之前，她不会接着再发。窗口不在前台且开启通知时，会用系统通知提醒你。每日上限针对长时间空闲的主动聊天，话题追发另按每轮一次限制。
- 这两种主动消息也会先显示「正在输入…」，都写进聊天记录（标记为主动发的），之后正常参与上下文和记忆提炼，导出、备份、导入时都会保留。

**安全底线不变**
- 危机关怀期间，以及结束后的 6 轮内，不会顺着话补发，也不发主动闲聊。主动消息只会是一条温和的关心：问问你现在怎么样，提一下 12356 和 110 / 120，每天最多一条。
- 你没回她的主动消息，她不会生气、埋怨、讨好或催你回复，你隔多久回来都一样。「痴迷」人设也不会纠缠，不会追问你在哪、和谁在一起，也不会连着发。
- 她生闷气的时候，主动消息会少一些，发也只是别别扭扭的一句，情绪不会因此升级。不约见面，也不承诺做不到的事。
- 补发时她自己从你最近说的几句话里挑话题，不为提取话题额外调用模型（生成消息本身仍需调用）；被要求不要每次都用「你刚才说」开头，也不提「关键词」这类字眼。

**运行、费用与升级说明**
- 两项功能分别设置「关 / 偶尔 / 正常」，默认均为「偶尔」。只有软件进程运行中（含托盘）才会触发；彻底退出后不会后台发送，也没有云端离线推送。
- 需要有效的 DeepSeek API Key 和网络。每次生成追发、主动聊天或关怀都会调用模型，按自己的 DeepSeek 账户计费；自动检查定时器本身不调用模型。可关闭两项功能控制费用。
- v1.7 沿用 v1.6 的 Electron 33.4.11，依赖未变。完全退出软件（含托盘）后，可备份并用 `app-1.7.0.asar` 替换安装目录内的 `resources/app.asar`。旧 exe 的 Windows 文件属性仍显示 1.6.0，但应用内版本来自新 asar，显示 1.7.0；需要更新文件属性则使用完整 1.7 包。请勿删除存放聊天与设置的用户数据目录。
- 更完整的版本记录见 [CHANGELOG.md](CHANGELOG.md)。

## 更新说明（v1.6.0）

**危机判断更准**
- 不再误会：「想死你了」「想死我了」（想念）、「热得想死」「累死了」「笑死我了」（夸张说法）、「跳楼价」「大甩卖」（促销）都不会再被当成危机，她会正常接话。
- 分轻重：明确的轻生、自伤说法（如「撑不下去了」「不想活了」）照旧进入至少 6 轮的危机关怀；「想死」「想消失」「活着没什么意思」这类常被随口说的话，只在这一轮认真问一句你是不是真的难受、有没有伤害自己的念头，不会一直锁住。如果她问完你只回「嗯」「是」「有」，会按认真的情况继续陪着；你说「没有啦，随口说的」，就正常聊。
- 补上了「活着有什么意思」「活着没什么意思」「死了算了」等说法。
- 「没事了，谢谢你陪我，再见」这类告别仍按原来的方式处理，这次没有改。

**她记得的事更守分寸**
- 不记敏感的事：健康、诊断和用药、心理状况，性取向，宗教，政治，借钱欠钱、赌博这类纠纷，别人的真实姓名（只记「室友」「导师」这样的称呼），对别人的负面评价，情绪很低落的具体描述，以及轻生、自伤相关的话，都不会被记下。提炼时先在提示词里禁止，提炼结果再过一遍本地关键词过滤。
- 危机关怀期间，以及结束后的 6 轮内，不做记忆提炼；之后提炼时也会跳过那段对话。
- 清空聊天时会弹出确认，可以勾选「同时清空她记得的事」（默认勾选）。勾选后记忆也会写进自动备份，点「撤销」时一起恢复。

**她记得的事带时间**
- 每条记忆都记着是什么时候提到的。聊天时她看到的是「下周三有面试（3 天前提到）」这样的说法，「她记得的事」里每条旁边也会显示时间。
- 「明天」「后天」「下周三」这类说法，会按你说这句话的那天换算成具体日期再记，比如「11月18日（周三）有面试」。
- 过了日期的事会标成「已经过去」，她会问你结果，不会再给你加油；考试、出差这类事件超过 30 天左右就不再提起。称呼、喜好这类长期的事不受影响。
- 去重改成按相似程度判断：信息更多的那条不会被一句更短的说法覆盖；同一件事换了说法或改了日期，以新的为准。v1.5 留下的记忆会自动补上时间，不用手动处理。

## 更新说明（v1.5.0）

**情绪更讲道理**
- 危机关怀会持续：她一旦听到轻生、自伤一类的话（「撑不下去」「想消失」「不想醒来」等说法都能识别），接下来至少 6 轮都认真关心你、头像不显示表情；就算你只回「嗯」「随便」，她也不会冷淡或生闷气。你说「好多了」「没事了，谢谢」才会慢慢回到平时的样子。求助方式仍是心理援助热线 12356，紧急情况拨 110 / 120。
- 你难过的时候她先顾你：说自己被骂、压力大、想哭时，她会把自己的小情绪放下，先按她的性格关心你。
- 久别重逢先想你：好几天没来，她第一反应是想念和惊喜，最多带一点点委屈，你随便说句话就过去了。生闷气只留给聊天中途的敷衍、失约这类明确的事；追问两次，她仍会说出原因。
- 不再误伤：「晚安」「好的」「收到」「在的」这类礼貌短句不算敷衍；「在忙」「去上班」「去学习」是正常安排，她会支持你；「我不喜欢你」不会被当成示好；一句话里有道歉时，先按道歉理解。
- 吃醋变少：和朋友、同事、家人出去不吃醋，只会让你回来讲讲；前任、暧昧对象、「别的女生/男生」才会吃醋，而且 24 小时内最多一次。沈清、许暖、顾书言吃醋只是淡淡一句。
- 口头禅不复读：她最近几轮说过的话、同一个开头、括号动作，会提醒她换个说法。

**新功能**
- 她记得的事：每聊 8 轮左右（以及换人设时），用一次很便宜的 DeepSeek 调用，从对话里提炼几条关于你的事（称呼、工作学业、喜好、近期的事、约定），最多 20 条，以后聊天会自然想起来。聊天页「她记得的事」可以查看、修改、删除、清空、自己添加；设置里可以关掉。不会记录 Key、密码、证件号、手机号这类信息。
- 发送失败可以重试：失败的那条下面有「重试」按钮，不用重新打字；请求还没发出去就失败时，原文会放回输入框。
- 复制和重新生成：鼠标放在气泡上会出现「复制」，她的最后一条还有「重新生成」。
- 搜索聊天记录：聊天页「搜索」（或 Ctrl+F），输入关键词会高亮并跳到对应位置，Enter / Shift+Enter 在结果之间切换。
- 导入和备份：「导出」菜单里可以「导入 JSON」（就是「导出为 JSON」得到的文件）和「从备份恢复」。清空前会自动备份到 `backups` 文件夹，清空后几秒内还能点「撤销」。
- 托盘和通知：关闭窗口时默认缩到右下角托盘，右键托盘图标可以退出；窗口不在前台时，她回复了会弹系统通知。两项都能在设置里关掉。

**新手体验**
- 第一次打开有三步引导：怎么拿 Key → 粘贴 → 自动测连接，成功后直接去选人。也可以先跳过，不填 Key 也能看人设。
- 人设卡片悬停能看两句示例对话；悬停卡片右上角的心情小脸能看大图。
- 设置页把模型名称、上下文轮数、回复温度、深度思考收进了默认折叠的「高级设置」。
- 夜蘅的首页标签改成「浓烈深情」，排在最后；第一次和她聊之前会弹一次说明，确认后才开始。
- 导出文件名会自动去掉 Windows 不允许的字符。

## 功能一览

- **七个人设**：高冷（沈清）· 可爱（林小满）· 粘人（苏糯）· 活泼（夏栀）· 温柔治愈（许暖）· 知性文艺（顾书言）· 浓烈深情/痴迷（夜蘅，首次进入前有一次说明）。所有角色都是成年人。人设卡片悬停能看示例对话。
- **夜间柔光风界面**：深色、低饱和、柔和渐变、细颗粒质感。每个人设都有一套跟性格相配的色调，切换人设时颜色约 1 秒渐变过渡，不会生硬跳色。
- **情绪会跟着聊天走**：她可能开心、兴奋、生气、生闷气、委屈、吃醋、困倦或低落，说话方式会跟着变；负面情绪都有具体原因，追问两次会说出来。头像角上会显示心情小表情（也可改回文字，或关掉）。
- **像真人一样回复**：先显示「正在输入…」，至少 1～2 秒后整条出现，可以随时停止。一次想说几句不连贯的话时，会拆成两条或多条气泡，中间有一点输入间隔。
- **她会主动找你**：有时顺着你刚说的话再补一句；你很久没聊时，最近聊过的那一位会在合适的时段主动找你。可以设成关、偶尔或正常，有每日上限，你没回就不再接着发。
- **记录与上下文**：每个人设单独保存一段对话；每次请求带最近 N 轮上下文（可调）；能导出成 TXT 或 JSON，也能导入 JSON；清空前自动备份，可以撤销或从备份恢复；可以搜索聊天记录。
- **她记得的事**：定期从对话里提炼几条关于你的小事，保存在本机，带提到的时间，过期的事会自动淡出；不记健康、性取向、宗教、政治、纠纷、别人的真实姓名这类敏感内容；可查看、编辑、删除，也可以关掉。
- **重试、复制、重新生成**：发送失败一键重试；悬停气泡可复制，她的最后一条可以重新生成。
- **托盘与通知**：关闭窗口可缩到托盘；窗口不在前台时，她回复了、或主动发来消息，都会发系统通知。
- **设置**：
  - API Key：用 Windows 系统加密（DPAPI）保存，不会明文写入磁盘。
  - 测试连接按钮。
  - 第一次打开有三步引导（拿 Key → 粘贴 → 自动测连接）。
  - 模型名称、上下文轮数、回复温度、深度思考开关在默认折叠的「高级设置」里。
  - 记忆开关、托盘与通知开关、「她主动找你」的频率（关 / 偶尔 / 正常）。
  - 可以设置她怎么称呼你。
- **安全底线**：写在每个角色的系统提示词里。
  - 不扮演未成年人。
  - 用户流露轻生念头时，角色会跳出人设认真关心，并给出求助方式：心理援助热线 12356，紧急情况拨 110 或 120。这种关心会持续几轮，直到你说自己好些了。
  - 不鼓励疏远现实中的亲友。
  - 「痴迷」人设的浓烈只停留在言语和意象上：不威胁，不以自伤要挟，不教任何跟踪或监控手段。

## 一、直接使用（不用装任何东西）

项目里的 `release\之间-1.7.0-win-x64-免安装版.zip` 是已经打包好的 Windows 64 位版本：

1. 把 zip **完整解压**到一个文件夹，例如 `D:\之间`。
2. 双击里面的 `之间.exe`。
3. 第一次打开会有三步引导：照着拿到 DeepSeek API Key，粘贴进去，软件会自动测一次连接。（也可以先跳过，之后在「设置」里填。）
4. 回到「人设」，选一个人开始聊天。

> 如果 Windows 弹出「已保护你的电脑」（SmartScreen），点「更多信息」→「仍要运行」。软件没有数字签名，所以会这样提示。

## 二、从源码运行 / 自己打包

前提：安装 [Node.js](https://nodejs.org/) 20 或更新的版本（LTS 即可）。

在项目文件夹（有 `package.json` 的那一层）打开 PowerShell：

```powershell
npm install          # 第一次需要，约 500 MB，下载几分钟
npm start            # 直接运行软件
npm run dist         # 打包出安装版和便携版 exe
```

`npm run dist` 完成后，在 `dist\` 文件夹里会得到：

- `之间-1.7.0-安装版.exe`：带安装向导，可以选安装位置，会创建桌面快捷方式。
- `之间-1.7.0-便携版.exe`：单个 exe，双击就能运行。
- `win-unpacked\之间.exe`：免安装的文件夹版本。

如果下载 Electron 很慢，可以先设置国内镜像再 `npm install`：

```powershell
$env:ELECTRON_MIRROR="https://npmmirror.com/mirrors/electron/"
$env:ELECTRON_BUILDER_BINARIES_MIRROR="https://npmmirror.com/mirrors/electron-builder-binaries/"
npm install
```

## 三、获取 DeepSeek API Key

1. 打开 <https://platform.deepseek.com>，注册并登录，然后充一点余额（几块钱能聊很久）。
2. 进入「API keys」，创建一个 Key，复制下来（`sk-` 开头）。
3. 在「之间」的「设置」里粘贴，点保存。

模型说明：DeepSeek 已于 2026 年 7 月停用旧的 `deepseek-chat` 名称，本软件默认使用 `deepseek-flash`（快、便宜）。想要更好的文笔可以改成 `deepseek-v4-pro`，价格更高。如果之后官方又改名，在设置里改模型名称即可。

## 四、添加 / 修改人设

人设都是 `personas\` 文件夹里的 JSON 文件，一个文件对应一个人。新增人设有两种方式：

- **从源码运行或自己打包**：把新文件放进项目的 `personas\` 文件夹，再 `npm start` 或重新 `npm run dist`。
- **已经打包好的软件**：在「设置 → 自定义人设 → 打开人设文件夹」里放入 JSON 文件，然后重启软件。如果和内置人设的 `id` 相同，会覆盖内置的那个。

最简单的做法是复制一个现有文件改。字段说明：

```jsonc
{
  "id": "xinren",                 // 英文/数字，唯一，也用作聊天记录文件名
  "order": 8,                     // 在列表里的顺序
  "type": "清冷御姐",              // 性格类型（卡片上的小标题）
  "name": "某某",                  // 角色名
  "age": 26,                      // 必须 ≥ 18，否则不会加载
  "intro": "一句话简介",
  "background": "成年人背景设定……",
  "keywords": ["关键词1", "关键词2"],
  "style": {
    "sentence": "句长习惯",
    "tone": "语气",
    "particles": "常用语气词",
    "emoji": "emoji 使用习惯",
    "address": "怎么称呼用户"
  },
  "habits": ["口头禅或小习惯", "……"],
  "examples": [ { "user": "用户说的话", "reply": "她的回复" } ],   // 3～5 条最好
  "boundaries": ["这个角色不能做的事", "……"],
  "theme": {                      // 配色：都用较暗、低饱和的颜色
    "bg": "#0c1016", "bg2": "#18202b", "glow": "#3d5266",
    "accent": "#a7bccf", "text": "#dfe6ec"
  },
  "greeting": "打开聊天时显示的第一句话"
}
```

全局安全规则在 `src/prompt.js`，会自动加到每个人设的提示词末尾，优先级最高，不需要在人设文件里重复写。

## 五、隐私说明

- 聊天内容只会发给 DeepSeek（`api.deepseek.com`）用来生成回复，不经过其他任何服务器。DeepSeek 怎么处理数据，以它的隐私政策为准。
- API Key 用 Electron safeStorage 加密保存。在 Windows 上就是 DPAPI，绑定当前 Windows 用户，拷到别的电脑或别的账户上无法解密。
- 聊天记录、设置、加密后的 Key 都在本机：`%APPDATA%\之间\`（设置页里会显示完整路径）。
  - `history\<人设id>.json`：聊天记录。
  - `settings.json`：设置。
  - `apikey.enc`：加密后的 Key。
  - `moods.json`：每个人设最近的心情状态（只有触发情绪的那句话的几个字片段，不含完整聊天记录和 Key）。
  - `memory\<人设id>.json`：「她记得的事」，几条关于你的简短事实和提到的时间，可以在软件里查看、编辑、清空，或者直接删掉这个文件夹。提炼时会把最近的聊天发给 DeepSeek 一次（和平时聊天走同一个接口）。不会记录 Key、密码、证件号、手机号、住址，也不会记录健康和用药、性取向、宗教、政治、财务纠纷、别人的真实姓名和负面评价，以及危机相关的内容。
  - `backups\<人设id>-<时间>.json`：清空聊天前的自动备份（清空时勾选了一并清空记忆，记忆也在里面），每个人设最多保留 10 份，可以随时删除。
- 想彻底清除，先在设置里「清除 Key」，再删掉上面这个文件夹。
- 软件里没有任何内置 Key，也没有统计或上报。
